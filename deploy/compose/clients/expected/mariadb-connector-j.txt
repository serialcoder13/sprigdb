# Statements and packets of 16 MiB and more. Through the gateway the backend
# limit is 16 MiB while the gateway answers 64 MiB, and on a debug gateway
# such a packet held a runtime worker until the runtime watchdog aborted the
# process (9 November 2026). On every target their buffers also push the
# test JVM past the container's 768 MB, which kills the fork and ends the run
# early. Left out everywhere.
* exclude org.mariadb.jdbc.integration.MultiPacketTest.* :: 16 MiB+ packets; backend limit 16 MiB; watchdog abort on a debug gateway; OOM-kills the 768 MB test container
* exclude org.mariadb.jdbc.integration.CompressTest.bigSend :: as MultiPacketTest
* exclude org.mariadb.jdbc.integration.*.big* :: every big* test sends 16 MiB+ (as MultiPacketTest)
* exclude org.mariadb.jdbc.integration.PreparedStatementTest.skippingRes :: 30 MB of parameters wherever @@max_allowed_packet is 64 MiB: through the gateway the backend drops it; on MySQL 8.4 it OOM-killed the 768 MB server
