# Format: <target-glob> <fail|skip|flaky|exclude> <test-glob> :: <reason>
# (summarize.py). Test ids are pytest's junit classname.name.

# Through the gateway the test sends a 16 MiB SELECT: @@max_allowed_packet
# reads 64 MiB (gateway.max_allowed_packet_bytes) while the development
# clusters keep 16 MiB (gaps row 30). On a debug gateway, lexing it also held
# a runtime worker long enough for the chapter 25 watchdog to abort the
# process (9 November 2026). Plain servers answer 16 MiB and the test returns.
gateway-* exclude *.test_largedata :: 16 MiB statement; backend limit 16 MiB (gaps row 30); watchdog abort on a debug gateway
