# MySQL Connector/J 9.7's DatabaseMetaData.getSQLKeywords() reads
# information_schema.KEYWORDS WHERE RESERVED = 1, which MariaDB doesn't have,
# so Hibernate can't resolve a dialect and validation fails before it looks
# at a table. On 3306 the gateway must answer that view: chapter 28's
# translator, milestone M0.5. The rest of the check runs after a restart
# without validation and must pass.
