## One layer, every model

<CardGrid>
  <Card title="The protocols your apps already speak" icon="puzzle">
    MySQL 8.4 and MariaDB on their own ports. MongoDB 8 drivers, `redis-cli`, Neo4j Bolt and Kafka clients connect unchanged. REST and gRPC sit on top. Tables, documents, keys, vectors, graphs and streams live in one store and join in one query.
  </Card>
  <Card title="Sharding without a DBA" icon="random">
    Tenants start on one shard. SprigDB watches the workload, chooses table groups and keys, then splits, merges and moves shards online. A fence and a two-second write pause keep every move correct.
  </Card>
  <Card title="Indexes from your queries" icon="rocket">
    Repeated slow queries get indexes designed from their predicates. Each index is validated on a replica first, rolled out a shard at a time, and dropped if it stops helping. Schema tools never see a drift.
  </Card>
  <Card title="Many data centres" icon="laptop">
    Tenants are routed and moved between data centres, pinned for residency, and failed over safely, using leases and fencing. That works with Galera, primary and replicas, single nodes or managed MariaDB.
  </Card>
  <Card title="Multi-tenant to the core" icon="seti:folder">
    Tenant trees, inherited settings, row-level security and per-tenant schemas, isolated by MariaDB's own grants. A tenant can share tables, streams and queues with its descendants.
  </Card>
  <Card title="Streams, queues, sinks and logic" icon="seti:pipeline">
    Kafka-compatible streams, AMQP queues, sinks to other systems, and functions and triggers in KIRun, JavaScript or Lua. All of them run next to the data.
  </Card>
  <Card title="You approve what matters" icon="approve-check">
    Every automatic decision can run on its own, wait for approval at the right level, or only recommend. That includes indexes, splits, moves and failovers. Notifications and an inbox come with it.
  </Card>
  <Card title="Studio and sprig" icon="laptop">
    A browser workspace and a terminal shell, with the same layout, keys and coral-gold calm: an explorer, a query editor, staged table edits, structure views, saved queries and history.
  </Card>
</CardGrid>

## Clients that work unchanged

<div class="compat">

| Model | Protocol and port | Clients |
|---|---|---|
| SQL | MySQL 8.4 (3306), MariaDB (3307) | `mysql`, `mariadb`, Connector/J, `go-sql-driver/mysql`, `mysql2`, PyMySQL, PHP PDO, Hibernate, SQLAlchemy, `mysqldump` |
| Documents | MongoDB 8 wire protocol | `mongosh`, MongoDB Java, Node, Python and Go drivers, Mongoose, Spring Data MongoDB |
| Key-value | Redis (RESP) | `redis-cli`, common Redis clients |
| Graphs | Neo4j Bolt, Cypher | `cypher-shell`, Neo4j drivers |
| Streams | Kafka | Kafka clients, `kcat` |
| Queues | AMQP 0-9-1 | RabbitMQ clients |
| APIs | REST and gRPC | `curl`, generated clients |

</div>
